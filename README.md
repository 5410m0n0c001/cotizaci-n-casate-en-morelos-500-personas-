# Cotización comparativa · 500 invitados · Boda o XV Años

**Presentada por Cásate en Morelos · Elaborada por Primavera Events Group®**

Propuesta web autocontenida (`index.html`) para un evento de 500 invitados con selector de tres recintos
(Jardín Tsú Nuum · Centro de Convenciones Presidente · Finca Las Isabeles), toggle Boda / XV Años,
contador de invitados y cotizador dinámico de extras. Mismo paquete integral y mismo precio por persona
($1,900 MXN) en los tres recintos; cada recinto con sus fotos, logo, video y datos propios.

Sitio: https://5410m0n0c001.github.io/cotizaci-n-casate-en-morelos-500-personas-/

- `index.html` — la cotización (única página).
- `index_original_tsunum_ana.html` — plantilla de origen (referencia, no se publica como página).
- `MATRIZ_IMAGENES_POR_VENUE.md` — qué imágenes son propias de cada recinto y cuáles faltan.
- `BRIEF_ANTIGRAVITY*.md`, `REPORTE_ANTIGRAVITY*.md` — briefs y reportes de construcción.
